## Cómo usar esta carpeta

- Nombres de archivo en inglés y contenido en español.
- Si algo no encaja en ningún documento, se anota en `open-questions.md` y luego se reubica.
- Cuando una pregunta abierta se resuelve, se borra de `open-questions.md` y se registra en `decisions.md` con la fecha.
- Las instrucciones para levantar el proyecto están en el [README principal](../README.md).
